# Redirection de progicleur.com

Ce dépôt sert uniquement à rediriger progicleur.com (sans www) vers
https://www.progicleur.com, le vrai site.

Ne pas supprimer ce dépôt : tant qu'il existe, il réserve le nom de domaine
sur GitHub Pages. Le supprimer pourrait permettre à quelqu'un d'autre de le
réclamer.
